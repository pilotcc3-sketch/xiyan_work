# 留在房间里的东西

移动端竖屏第一人称友情剧情 H5 原型，本章为《她妈妈要来》。

## 运行

在本目录启动任意静态服务器，例如：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

然后访问 `http://127.0.0.1:4173`。无需构建、后端、登录或外部资源。

## 操作

- 轻点物品：拿起检视、翻转细节、选择处置位置。
- 长按物品或检视画面：进入可玩回忆。
- 拖动物品：直接拖到房间里的明面、暗处、纸箱或阿岚手边。
- 左右滑动场景：切换卧室门边与客厅茶几视角。
- 整理至少四件物品后，可走到玄关门边完成本章。
- 每次处置后可撤销；重来会清空本局，保留已见结局和探索记录。

## 内容

- 七件可检视、可处置物品。
- 七段独立触屏微回忆，均可跳过。
- 合照与钥匙、纸箱与转账记录的关联细节。
- 《留下》《坦白》《客气》《失衡》四种基础结局。
- 结局最后动作会根据本局是否探索相关回忆而变化。
- `localStorage` 保存当前进度、已见结局、已探索回忆、静音和触感设置。

## 文件

- `index.html`：页面与交互层结构。
- `styles.css`：竖屏场景、动效和响应式样式。
- `js/data.js`：物品、回忆文本、处置反馈与结局数据。
- `js/audio.js`：Web Audio 环境声、动作音效与触感。
- `js/app.js`：场景、拖拽、检视、回忆、关系逻辑与存档。
- `assets/room-clean-plate-v2.png`：移除七件可交互物品后的房间干净底板。
- `assets/items/`：七张带 Alpha 通道的独立物品 PNG 与坐标数据。
- `assets/room-seven-items-v3.png`：七件物品融入房间后的已确认参考图。
- `assets/photo-memory.png`：合照检视与天台回忆使用的本地图片。
- `js/scene-items.js`：物品图层在原始 1024 × 1536 画布中的位置和尺寸。
- `tools/extract_scene_items.py`：从确认参考图重新提取透明物品图层的脚本。

房间使用“干净底板＋独立物品图层”渲染。轻点、长按和拖动直接作用于图片中的真实物品；收起或装箱后物品图层淡出，撤销时恢复。歌单与转账记录在检视层使用真实可点击界面。
